# Changelog

형식: [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/), 버전: [SemVer](https://semver.org/lang/ko/).

## [1.0.0] - 2026-11-26

### 추가
- Unity TMPEffect 1.0.2를 Godot 4.7로 이식.
- `CatText`: Label을 대체하는 글자 단위 렌더러.
- `CatTextOutline`, `CatTextGlow`, `CatTextCurve`, `CatTextAnimation` 효과 노드.
- `CatMaskFlow`, `CatLayoutLimiter`(Label에서도 동작).
- `CatTextStylePreset`, `CatTextAnimationPreset` 리소스와 번들 프리셋 10종.
- 원본에 없던 신호: `animation_finished`, `impact_finished`, `turn_changed`.
