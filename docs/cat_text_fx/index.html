CAT Text FX

Godot 게임 UI 텍스트에 외곽선, 그림자, 글로우, 곡선 배치, 글자별 등장·퇴장 애니메이션을 붙이는 애드온입니다. Unity TextMeshPro용으로 쓰던 TMPEffect를 Godot으로 옮겼고, 노드를 붙이고 인스펙터 값만 바꾸면 됩니다.

스타일

CatText 아래에 CatTextOutline이나 CatTextGlow를 자식으로 붙입니다. 그리는 순서는 뒤에서 앞으로 그림자, 글로우 번짐, 외곽선, 본문, 안쪽 면, 안쪽 글로우입니다.

외곽선 CatTextOutline

글자 바깥에 두께와 색을 가진 테두리를 둘러 밝은 배경에서도 읽히게 합니다. 소프트니스를 올리면 가장자리가 부드럽게 번집니다.

underlay_color외곽선 색
underlay_dilate두께 0~1 (기본 0.15)
underlay_softness가장자리 번짐 0~1
face_dilate본문 글자 굵기 0~1
var outline := CatTextOutline.new()
outline.set_outline(Color.BLACK, 0.3)
label.add_child(outline)

그림자 CatTextOutline

두 가지 그림자를 씁니다. 외곽선을 한쪽으로 밀면 입체감 있는 드롭 섀도가 되고, Shadow를 켜면 외곽선까지 포함한 글자 실루엣이 반투명하게 하나 더 깔립니다.

underlay_offset_x / y외곽선을 밀어 만드는 드롭 섀도 (-1~1)
enable_shadow실루엣 그림자 켜기
shadow_offset글자 크기 대비 이동량 (기본 0.1, 0.1)
shadow_alpha그림자 진하기 0~1
outline.set_outline_with_shadow(Color.BLACK, 0.3, 0.5, Vector2(0.08, 0.08))

안쪽 면 Second Face

글자 안쪽에 한 겹 작은 면을 다른 색으로 그려, 타이틀 로고처럼 테두리가 두 겹인 느낌을 냅니다. 단색이나 네 모서리 그라디언트를 쓸 수 있습니다.

enable_second_face안쪽 면 켜기
second_face_color안쪽 면 색
use_second_face_gradient네 모서리 그라디언트 사용
second_face_dilate안쪽으로 줄이는 양 -1~0 (기본 -0.1)

그라디언트는 글자마다가 아니라 텍스트 전체 영역 기준으로 섞입니다.

글로우 CatTextGlow

글자 주변으로 빛이 번지는 효과입니다. 본문 색도 글로우 색을 따라가서 네온사인처럼 보입니다.

glow_color빛 색과 세기 (RGBA)
glow_range번지는 범위 0~1
inner_glow_alpha글자 위에 겹치는 안쪽 빛 0~1
var glow := CatTextGlow.new()
glow.set_glow(Color(1, 0.6, 0.1, 0.6), 0.4)
label.add_child(glow)

스타일 프리셋 CatTextStylePreset

외곽선·그림자·안쪽 면·글로우 설정을 .tres 파일 하나로 저장해 여러 텍스트에 같은 스타일을 씁니다. 인스펙터의 새 프리셋으로 저장 버튼으로 현재 값을 바로 저장할 수 있습니다.

설명용Desc_Black, Desc_Black_Shadow
타이틀용Title_Extrude_Brown, Title_Out1_Purple_Shadow, Title_Out2_Red_Shadow
글로우Glow_Green
outline.apply_preset(load("res://addons/cat_text_fx/presets/style/Title_Out2_Red_Shadow.tres"))

배치

글자를 직선이 아닌 곡선 위에 놓습니다. 애니메이션과 함께 쓰면 애니메이션이 먼저, 곡선이 나중에 적용됩니다.

곡선 CatTextCurve

Godot의 Curve 리소스로 텍스트 모양을 그립니다. 가로축은 텍스트 왼쪽에서 오른쪽(0~1), 세로축은 높이입니다. 기울기를 따라 글자를 돌릴 수 있고, 글자 수나 폰트 크기가 바뀌어도 곡선 세기가 자동으로 맞춰집니다.

curve곡선 모양 (비워 두면 평평)
curve_scale곡선 높이(px)
rotate_along_curve기울기 방향으로 글자 회전
enable_dynamic_curve_scale글자 수·크기에 따라 세기 자동 보정
var curve := CatTextCurve.new()
label.add_child(curve)
curve.set_arch_curve(40)        # 아치
curve.set_wave_curve(18, 2)     # 물결 2번

애니메이션

CatTextAnimation 하나로 등장, 반복, 퇴장을 이어서 재생합니다. 글자마다 시작 시각이 character_delay만큼 밀려 한 글자씩 움직이고, 이징은 31종 중에서 고르거나 Curve로 직접 그립니다. 에디터에서는 인스펙터의 미리보기 재생 버튼으로 실행 없이 확인합니다.

등장 Appear

글자가 지정한 위치·크기·회전·투명도에서 출발해 제자리로 들어옵니다.

appear_position출발 위치 (기본 위쪽 50px)
appear_scale / rotation / alpha출발 크기·회전(도)·투명도
appear_duration글자 하나가 들어오는 시간
appear_ease이징 (기본 OUT_BACK)

반복 Loop

등장 후 글자가 계속 출렁이거나 커졌다 작아집니다. YOYO는 갔다가 되돌아오고, RESTART는 처음으로 돌아가 다시 시작합니다.

loop_position / scale / rotation반복 중 움직임 폭
loop_duration한 방향 시간
loop_count반복 횟수 (-1 = 무한)
loop_typeYOYO / RESTART

퇴장 Disappear

글자가 한 글자씩 지정한 상태로 빠져나갑니다. 끝나면 animation_finished 신호가 와서 다음 연출을 이어 붙이기 쉽습니다.

disappear_position / scale / alpha도착 상태
disappear_duration글자 하나가 나가는 시간
disappear_ease이징 (기본 IN_BACK)
await anim.animation_finished
label.queue_free()

전체 시퀀스 Blend

등장 → 반복 → 퇴장을 한 번에 재생합니다. 블렌드 값을 주면 다음 단계가 조금 일찍 시작해 단계 사이가 끊기지 않고 자연스럽게 이어집니다.

appear_to_loop_blend등장→반복 겹침 0~0.5
loop_to_disappear_blend반복→퇴장 겹침 0~0.5
character_delay글자 간 시작 간격(초)
pivot회전·확대 기준점 (0.5, 0) = 가운데 아래

임팩트 trigger_impact()

점수 획득, 콤보처럼 순간적으로 강조할 때 씁니다. 재생 중인 애니메이션 위에 덧씌워져 글자가 잠깐 커졌다가 돌아옵니다.

impact_scale최대 확대 배율 (기본 1.2)
impact_position / rotation순간 이동·기울기
impact_duration커졌다 돌아오는 전체 시간
impact_character_delay글자 간 파도 간격
func _on_score_changed(v):
    score_label.text = str(v)
    score_anim.trigger_impact()

애니메이션 프리셋 CatTextAnimationPreset

자주 쓰는 움직임을 파일이나 코드 한 줄로 적용합니다.

번들 .tresTitle_Notice_Red, Appear_RB_Loop_1, Preset_A, Description_Loop
코드 팩토리bounce_appear, wave_loop, scale_disappear, rotate_appear, fade_in_out
anim.apply_preset(CatTextAnimationPreset.create_wave_loop())

레이아웃

아래 두 노드는 CatText뿐 아니라 이미 쓰고 있는 일반 Label에도 붙일 수 있습니다.

전광판 흐름 CatMaskFlow

정해진 영역 안에서 텍스트가 흐릅니다. 왼쪽·오른쪽은 문구가 이어진 띠로 계속 흐르고, 위·아래는 한 줄씩 교체됩니다. static 모드에서는 영역에 들어가는 짧은 문구는 멈춰 있고 넘치는 문구만 흐릅니다.

directionLEFT / RIGHT / TOP / BOTTOM
velocity · gap속도(px/s) · 문구 사이 간격
interval위·아래 교체 후 대기 시간
static_mode넘칠 때만 흐름
text_entries차례로 보여줄 문구(번역 키 가능)

사용법: CatMaskFlow를 만들고 첫 번째 자식으로 Label이나 CatText를 넣습니다. 복제본은 씬 파일에 저장되지 않습니다.

최대 크기 제한 CatLayoutLimiter

짧은 문구는 자연스러운 폭을 유지하고, 최대 폭에 닿으면 그때부터 줄바꿈합니다. 말풍선이나 툴팁처럼 길이가 들쭉날쭉한 문구에 맞습니다. 번역문 길이를 기준으로 판단합니다.

max_width이 폭에 닿으면 줄바꿈 (기본 300)
max_height이 높이에 닿으면 고정하고 잘라냄 (0 = 제한 없음)

설치

addons/cat_core와 addons/cat_text_fx 두 폴더만 있으면 됩니다. 노드는 class_name으로 등록되어 플러그인을 켜지 않아도 노드 추가 목록에 나타납니다.

폴더 복사

GitHub 레포에서 두 폴더를 받아 프로젝트의 addons/에 넣습니다.

your_project/
└─ addons/
   ├─ cat_core/
   └─ cat_text_fx/

GodotEnv로 버전 고정

프로젝트에 addons.json을 만들고 godotenv addons install을 실행합니다.

{
  "path": "addons",
  "addons": {
    "cat_core": { "url": "https://github.com/zzamjak-cloud/Godot_Addon.git",
      "checkout": "cat_core/v1.0.0", "subfolder": "addons/cat_core" },
    "cat_text_fx": { "url": "https://github.com/zzamjak-cloud/Godot_Addon.git",
      "checkout": "cat_text_fx/v1.0.0", "subfolder": "addons/cat_text_fx" }
  }
}

원본과 다른 점

  • SDF 셰이더 대신 테두리를 여러 겹 그려 외곽선과 번짐을 만들어서, 두께 느낌이 조금 다를 수 있습니다.
  • 회전은 z축만 지원합니다.
  • OutBack처럼 튀어 나가는 이징이 실제로 튑니다. 원본처럼 자르려면 clamp_overshoot를 켭니다.
  • Godot은 y축이 아래쪽이라 위치·회전 값의 부호가 원본 프리셋과 반대입니다. 번들 프리셋은 이미 변환되어 있습니다.
  • 원본에 없던 신호 animation_finished, impact_finished, turn_changed를 추가했습니다.
