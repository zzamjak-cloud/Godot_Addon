CAT Ocean Flow

Godot 3D에서 카툰 스타일 바다와 강을 그리는 애드온입니다. 물가 포말, 깊이 색, 셀 거품, 난류, Gerstner 파도, 셀 톤 하이라이트를 같은 셰이더로 켜고 끕니다. Unity URP용 OceanFlow를 Godot으로 옮겼습니다.

  • 바다·강 노드 2종
  • 기능별 셰이더 조합
  • 수평선 바다 세트
  • Forward+ · Mobile 지원
GitHub에서 받기 설치 방법
물가와 색 접경 포말깊이 색 수면 무늬 셀 거품노이즈 난류흐름 채널 파동과 빛 파동하이라이트 바다와 강 강수평선 설치

물가와 색

물 아래에 지형(불투명 메쉬)이 있으면 씬 깊이와 수면 깊이의 차로 얕은 곳을 알아냅니다. 얕을수록 흰 포말과 옅은 색, 깊을수록 짙은 색으로 변합니다.

접경 포말 shore_foam_enabled

물과 지형이 만나는 곳에 흰 물결 띠를 그립니다. 두께는 수중 깊이로 정하고, 노이즈로 가장자리를 일렁이게 합니다. 포말 노이즈는 channel0이 흘립니다.

foam_distance포말 띠 두께, 수중 깊이 기준 (기본 0.6)
foam_cutoff노이즈 경계값 — 높을수록 포말이 줄어듭니다 (기본 0.6)
foam_softness / foam_noise_amount가장자리 부드러움 / 노이즈 세기
foam_fade_start / end먼 물가의 깜빡임을 줄이려고 포말을 지우는 거리 (기본 0 ~ 300 m)
ocean.foam_distance = 0.8
ocean.foam_cutoff = 0.5
ocean.channel0.speed = 0.1   # 포말 노이즈 흐름

포말 띠 두께는 시선 각도에 의존합니다. 물가 경사가 시선보다 급하면 포말이 사라집니다.

깊이 색 depth_fade_distance

수면 아래 깊이에 따라 얕은 색에서 깊은 색으로 섞고 알파도 함께 바꿉니다. 거리를 줄이면 물가에서 금방 짙어지고, 늘리면 넓게 옅은 물이 퍼집니다.

shallow_color / deep_color얕은 곳 / 깊은 곳 색
shallow_alpha / deep_alpha두 곳의 투명도 (기본 0.5 / 0.95)
depth_fade_distance얕은 색에서 깊은 색으로 넘어가는 수중 거리 (기본 3.0)
ocean.shallow_color = Color(0.45, 0.90, 0.92)
ocean.deep_color = Color(0.06, 0.28, 0.55)
ocean.depth_fade_distance = 3.0

직교(Orthographic) 카메라에서도 동작합니다. 원본은 원근 카메라 전용이었습니다.

수면 무늬

수면 노이즈 텍스처 하나를 두 레이어로 흘려 셀 거품을 만듭니다. 난류와 흐름 채널로 무늬가 어떻게 움직일지 정합니다.

셀 거품 cell_foam_enabled

흐르는 노이즈를 단계화해 만화처럼 또렷한 거품 무늬를 만듭니다. 경계값을 낮추면 거품이 넓어지고, 세기는 수면에 얹히는 흰색의 진하기입니다.

cell_cutoff노이즈 경계값 0~1 — 낮을수록 거품이 많음 (기본 0.72)
cell_softness경계 부드러움 (기본 0.03)
cell_intensity거품 세기 (기본 0.5)
cell_color거품 색
ocean.cell_cutoff = 0.6
ocean.cell_intensity = 0.8

노이즈 난류 noise_churn_enabled

노이즈를 UV로만 흘리면 그물망 무늬가 통째로 미끄러집니다. 난류는 반주기 엇갈린 두 위상을 교차 페이드해 무늬가 태어나고 사라지게 하므로 실제 물결처럼 보입니다.

churn_speed초당 재배치 사이클 수 (기본 0.12)
churn_jitter사이클마다 옮겨 앉는 거리 (기본 0.5)
churn_warpUV를 비트는 양 (기본 0.06)
churn_rotation사이클마다 돌아가는 각도 폭, 라디안 (기본 0.6)
ocean.noise_churn_enabled = true
ocean.churn_speed = 0.5

셋을 모두 0으로 두면 단순 스크롤과 같습니다.

흐름 채널 CatFlowChannel

채널 하나가 노이즈 UV 레이어 하나의 움직임을 정합니다. 채널 0은 접경 포말, 채널 1은 수면 셀 거품을 흘립니다. 이징은 CatEase 31종이나 Curve를 씁니다.

modeLOOP: 한 방향 무한 / PING_PONG: range 폭을 왕복
direction / speed방향 / Loop는 초당 UV 이동량, PingPong은 1왕복 초
rangePingPong 왕복 폭 (UV)
ease / custom_curveCatEase.Type 또는 EASE_CUSTOM + Curve
tiling레이어 UV 타일링
var ch := ocean.channel1
ch.mode = CatFlowChannel.Mode.PING_PONG
ch.range = 0.3
ch.speed = 2.0
ch.ease = CatEase.Type.OUT_BOUNCE

노드를 복제해도 채널은 공유되지 않습니다.

파동과 빛

수면 움직임은 정점 셰이더(GPU)가 맡아 CPU 비용이 없습니다. 켠 기능만 셰이더에 들어갑니다.

파동 wave_enabled

Gerstner 파 2개에 잔물결을 더하고 법선은 해석적으로 구합니다. 파동 값은 방향 xy, 가파름 z, 파장 w를 한 Vector4에 담습니다. 위상 지터와 너울 변화가 지역마다 마루선을 비틀고 진폭을 달리해 바다 전체가 똑같이 반복되지 않습니다(텍스처 없이 정점 셰이더에서 계산).

wave_a / wave_bGerstner 파 (방향 xy, 가파름 z, 파장 w). 기본 A = (1, 0, 0.25, 8), B = (0.34, 0.94, 0.15, 5.1). 두 파는 방향을 크게(약 70°) 다르게, 파장비를 정수비가 아니게 둡니다
ripple잔물결 (진폭 x, 주파수 y, 속도 z). 기본 (0.04, 3, 1.5). 방향이 다른 방향파 3개 합이라 격자 무늬가 없음
wave_phase_jitter지역별 위상 비틀기 0~1 — 마루선이 곧게 이어지지 않음 (기본 0.5)
swell_variation지역별 진폭 감소 0~1 — 너울 묶음, 진폭을 키우지는 않음 (기본 0.4)
swell_scale너울 묶음 크기 m (기본 40, 강 10)
wave_edge_fade패치 가장자리에서 파도를 줄이는 비율 (이음매 보호)
ocean.wave_a = Vector4(1, 0, 0.4, 8)
ocean.ripple.x = 0.06
ocean.wave_phase_jitter = 0.8
ocean.swell_variation = 0.6

가파름 합이 1을 넘으면 수면이 접힙니다. 파장은 정점 간격의 4배 이상이어야 파도로 보입니다.

하이라이트 highlight_enabled

메인 라이트 방향으로 셀 톤 반짝임을 그립니다. 법선이 빛을 반사하는 곳만 흰색으로 끊어 그려 만화 같은 윤슬이 됩니다. 얼룩(surface_breakup)이 반짝임과 셀 거품을 구역마다 빽빽하거나 성기게 만들어 고르게 깔리지 않고, 법선 비틀기(highlight_normal_jitter)가 반짝임이 파도 마루를 따라 평행 띠로 늘어서지 않게 흩뜨립니다.

highlight_cutoff반짝임 경계 — 낮을수록 넓음 (기본 0.5)
highlight_power집중도 (기본 64)
highlight_intensity세기 (기본 0.8)
main_light빛 지정. 비우면 씬의 첫 DirectionalLight3D
surface_breakup반짝임·셀 거품 얼룩 0~1 — 구역별 개수·밝기 차, 평균은 유지 (기본 0.6)
surface_breakup_scale얼룩 크기 m (기본 25, 강 8). 정점이 드문 먼 바다에는 적용 안 함
highlight_normal_jitter하이라이트 계산에서만 법선을 저주파로 기울이는 세기 0~1 (기본 0.7). 0이면 끔, 텍스처 페치 추가 없음
ocean.highlight_cutoff = 0.7
ocean.main_light = $Sun
ocean.surface_breakup = 0.8

바다와 강

같은 셰이더로 넓은 바다와 굽이치는 강을 모두 그립니다.

강 CatOceanFlowRiver

Curve3D 경로를 따라 리본 메쉬를 만들고 폭 곡선으로 위치마다 폭을 바꿉니다. 에디터에서는 자식 EditPath의 기즈모로 점과 핸들을 옮기면 물길이 따라옵니다. 긴 강은 next_river로 이어 붙입니다.

curveCurve3D 경로 (강 노드 로컬 좌표)
width / width_curve기준 폭 / 경로 위치별 폭 배율 Curve
length_samples / width_segments길이·폭 방향 분할 수 (기본 64 / 4)
uv_length_scaleUV 한 바퀴당 길이 m (기본 8)
next_river뒤 구간 동기화 — 시작 v가 이음매에서 이어짐
var river := CatOceanFlowRiver.new()
river.width = 6.0
river.curve.add_point(Vector3(0, 0, 30), Vector3(0, 0, -4), Vector3(0, 0, 4))
add_child(river)

length_samples 상한이 512라 아주 긴 강은 여러 노드로 나눕니다.

수평선 create_ocean_set()

균일 그리드 하나로는 수평선까지 덮을 수 없어 두 장을 씁니다. 촘촘한 근거리 패치가 카메라 시선이 수면과 만나는 점을 따라다니고, 1000 m 먼 바다가 그 아래를 채웁니다. 근거리 패치만 조정하면 먼 바다가 따라옵니다.

follow_camera실행 중 뷰포트 카메라를 따라 이동 (기본 꺼짐)
hole_size근거리 패치 자리를 먼 바다에 뚫는 구멍
far_surface먼 바다 동기화 대상
wave_edge_fade근거리 패치 가장자리 파도 페이드 (세트 기본 0.15)
add_child(CatOceanFlowSurface.create_ocean_set())

배경이 단색이면 바다 끝이 직선으로 잘리므로 배경색과 같은 안개를 켜세요.

설치

addons/cat_core와 addons/cat_ocean_flow 두 폴더만 있으면 됩니다. 노드는 class_name으로 등록되어 플러그인을 켜지 않아도 노드 추가 목록에 나타납니다. 깊이 기반 포말은 Forward+ 또는 Mobile 렌더러에서 확인하세요.

폴더 복사

GitHub 레포에서 두 폴더를 받아 프로젝트의 addons/에 넣습니다.

your_project/
└─ addons/
   ├─ cat_core/
   └─ cat_ocean_flow/

GodotEnv로 버전 고정

프로젝트에 addons.json을 만들고 godotenv addons install을 실행합니다.

{
  "path": "addons",
  "addons": {
    "cat_core": { "url": "https://github.com/zzamjak-cloud/Godot_Addon.git",
      "checkout": "cat_core/v1.0.0", "subfolder": "addons/cat_core" },
    "cat_ocean_flow": { "url": "https://github.com/zzamjak-cloud/Godot_Addon.git",
      "checkout": "cat_ocean_flow/v1.0.0", "subfolder": "addons/cat_ocean_flow" }
  }
}

원본과 다른 점

  • 셰이더 키워드 대신 켠 기능 조합마다 코드로 만든 셰이더를 공유합니다(꺼진 기능은 셰이더에서 빠짐).
  • 선형 깊이를 직접 구해서 직교 카메라에서도 포말과 깊이 색이 동작합니다.
  • 물은 unshaded이고, 메인 라이트는 main_light 또는 씬의 첫 DirectionalLight3D를 씁니다.
  • 60초 미리보기 버튼이 없습니다. @tool 노드가 에디터에서 바로 흐릅니다.
  • 강 경로는 전용 편집기 대신 Godot Path3D 기즈모로 편집합니다.
  • 이징은 CatEase.Type(1부터)이며 Custom은 32입니다.
  • 카메라 추적 시 두 바다의 노이즈 이음매 어긋남을 UV 보정으로 고쳤습니다.
  • 파동 위상 지터·너울 변화·거품/반짝임 얼룩을 더했고, 잔물결을 격자 대신 방향파 3개 합으로 바꿨습니다. 새 값을 0으로 두면 잔물결 모양만 원본과 다릅니다.
